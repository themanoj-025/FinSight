# FinSight Agent — Documentation Index

Single home for all FinSight Agent documentation. FinSight Agent is an
agentic personal-finance system with natural-language querying, dashboards,
fraud detection, and deterministic offline mode.

**Start here:** [architecture.md](architecture.md) (system map) →
[folder_structure.md](folder_structure.md) (repo tree) →
[technical/TechSpec.md](technical/TechSpec.md) (build details).
